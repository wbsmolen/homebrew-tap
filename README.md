# homebrew-tap

Homebrew casks for [AeroSpork](https://github.com/wbsmolen/aerospork), an i3-like tiling window
manager for macOS.

```bash
brew install --cask wbsmolen/tap/aerospork
```

The cask installs `aerospork.app` into `/Applications`, links the bundled CLI onto your `PATH` as
`aerospork`, and installs the man pages and bash/fish/zsh completions.

Builds are universal (arm64 + x86_64), signed with a Developer ID, notarized by Apple and stapled,
so Gatekeeper accepts them on first launch without stripping the quarantine attribute.

`Casks/aerospork.rb` is generated by `script/build-brew-cask.sh` in the main repository. Edit it
there, not here.
